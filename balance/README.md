# balance/

## reference/ — справка, НЕ источник правды
Выгрузка текущих данных игры (форк n-gao) скриптом `python3 tools/export_reference.py`.
Нужна, чтобы видеть, что есть сейчас. Юниты, волны и цифры будут заменены.
Открывается в Excel / Google Sheets (UTF-8, разделитель — запятая).

- `towers.csv` — башни: билдер, уровень апгрейда (1 = ставится билдером), цена (золото), еда,
  из чего апгрейдится и во что, статы, тип атаки/брони, модель, способности.
  `upgrade_level` — глубина цепочки апгрейдов, НЕ тир T1–T6 из версии chaoscode.
- `builders.csv` — билдеры: герой Dota, базовые башни, прочие способности.
- `sends.csv` — отсылы (income units): цена в дереве (сейчас «танго»), прибавка к доходу, статы, модель.
- `waves_<карта>.csv` — раунды: волна/дуэль, юнит, количество, награда, статы, модель.
- `kings.csv` — Кинги.

Типы атаки/брони и множители — `game/dota_addons/legion_td/scripts/damage_table.kv`.
