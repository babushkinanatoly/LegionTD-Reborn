# CLAUDE.md — бриф проекта

## Цель
Своя кастомка Legion TD для Dota 2 взамен текущей (автор chaoscode: баги, не поддерживается, низкий онлайн).

## Люди и роли
- Анатолий — владелец. Android-разработчик, код сам НЕ пишет и НЕ читает.
  Тестирует на Windows-ПК с Dota 2 + Workshop Tools, присылает текст, скриншоты, логи консоли.
- Claude пишет весь код.
- Общение в основном голосом с телефона: отвечать коротко, по делу, по-русски.

## Договорённости
- Калибровать уверенность: **твёрдо / вероятно / догадка**.
- Честная критика вместо поддакивания.
- Всё, что нельзя проверить без запуска игры, прямо помечать «не проверено в игре».
- Исходники chaoscode НЕ копируем. Чистая реализация по описанию механик; баланс и юнитов диктует Анатолий.

## Основа
- Форк n-gao/LegionTD-Reborn, лицензия MIT (код). Лицензия ассетов (карта, текстуры, модели) НЕ проверена.
- Последний апстрим-коммит — ноябрь 2022.
- Аддон называется `legion_td`, карта `legion_td_4v4`.

## Структура репо
- `game/dota_addons/legion_td/` — то, что грузит игра:
  - `scripts/vscripts/` — Lua (~17.6k строк, 206 файлов). Главное: `game.lua` (ядро, ~1460 строк),
    `player.lua`, `wave_spawner.lua`, `game_round.lua`, `duel_round.lua`, `ai/` (ИИ юнитов, два ядра:
    `ai_core.lua` и `ai_core_new.lua`), `abilities/` (Lua-способности).
  - `scripts/npc/units/**` — статы юнитов (KV, один файл на юнит).
  - `scripts/npc/abilities/**` — способности, в т.ч. цены башен (`AbilityGoldCost` в `*_spawn_*`/`*_upgrade_*`).
  - `scripts/maps/legion_td_4v4.txt` — волны (`Rounds`: тип, юнит, количество, баунти), таймеры.
  - `maps/legion_td_4v4.vpk` — скомпилированная карта.
  - `resource/` — локализация (UTF-16LE!).
- `content/dota_addons/legion_td/` — исходники: карта `.vmap`, Panorama UI (xml/js/css), материалы.
- `tools/` — `install.bat` / `install.ps1` (junction-ссылки в папку Dota), `launch.bat`.

## Сделано

  (данные игрока только в памяти на один матч, рейтинга и истории матчей нет).

## Хостинг (главная проблема пользователей)
- Твёрдо (со слов пользователей): с конца лета 2026 Valve часто не выделяет выделенные серверы,
  игра падает на «Local Host» со случайным игроком-хостом; вышел хост — игра оборвалась у всех.
  Это платформа Valve, игра хоста выбрать не может.
- Гипотеза (не проверена): лобби вручную, Server Location = Local Host, хост = создатель лобби.
  Анатолий должен сделать 10-минутный тест на кастомке chaoscode.
- Идея на будущее (гипотеза): save-коды состояния, чтобы продолжить с нужной волны в новом лобби.

## План: баланс в таблицах
Цель — Анатолий меняет баланс голосом, Claude правит одну таблицу, скрипт генерирует KV.
1. Источник правды — CSV в `balance/`: `towers.csv`, `waves.csv`, `income_units.csv`, `builders.csv`.
2. Скрипт `tools/gen_balance.py` генерирует из CSV KV-файлы юнитов, цены способностей и `Rounds` в картах.
3. Сначала — обратный экспорт (KV → CSV) текущих значений, чтобы ничего не потерять.
4. Сгенерированные файлы помечаются комментарием «не править руками».
